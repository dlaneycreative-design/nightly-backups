# Nightly Backups

Your three sites are backed up here every night at **3:00 AM Denver time**.

## The three sites

| Site | Where its backup lives |
|------|----------------------|
| **LlamaChat** | In each dated folder below, as `llamachat-v2.tar.gz` (LlamaChat isn't in git, so we save the actual files) |
| **Studio** (thestudio.io) | In the [thestudio-io repo](https://github.com/dlaneycreative-design/thestudio-io), under the tag matching the date (e.g. `nightly-2026-10-09`) |
| **E2** (e2planet.com) | Same as Studio, it's inside the thestudio-io repo under the same date tag |

## How to get a site back

**LlamaChat:** download the `llamachat-v2.tar.gz` from the date you want, unzip it, that's the whole site.

**Studio or E2:** go to the [thestudio-io repo](https://github.com/dlaneycreative-design/thestudio-io), click Tags, pick the date you want, browse or download the code at that point.

## Backup folders

Each folder is one night. Newest at the bottom.
